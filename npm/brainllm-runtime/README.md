# @christianirack/brainllm-runtime

The runtime of [BRAINLLM](https://chrisifm.github.io/BRAINLLM/), the web compiler for LLMs built in Rust: dependency-free ES modules (signals, DOM, router, data, forms, channels, service worker, server).
The `brain` binary embeds this same version and serves it at `/@brain/*`; install this package only for tooling that
needs the modules on disk.
