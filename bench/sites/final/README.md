# #21 final — two sites built by an LLM through the brain MCP tools only, then measured

Two dummy sites from one-paragraph briefs (`bench/autonomy/briefs-21.json`): a marketing landing ("Nubo") and a SaaS
admin panel with CRUD ("Nubo Admin"). Each was generated by `claude -p` with **only** the `brain` MCP server (mode
`mcp`: no Bash, no host Read/Write, no web, no human turns), by Sonnet 5.5 (primary pair) and Haiku 5.5 (second data
point), then measured per `../PROTOCOL.md` §3. Every number below comes from `results/*.json`; the tables are
`results/summary.md` (regenerated by `summarize.mjs`).

This is the **second run (`final21b`)**, made after the fixes for the nine defects F1–F9 of the first run (`final21`).
The re-check of each defect is at the end.

- `apps/landing/`, `apps/panel/` — the generated **sources** of the two Sonnet apps (no `dist/`, `.brain/`,
  `node_modules/`, `.brain_env`).
- `results/generation-{sonnet,haiku}.json` — the harness report per model (tool calls per tool, tokens, cost, doctor).
- `results/{sonnet,haiku}-{landing,panel}.json` — every measurement, with per-resource bytes and smoke evidence.
- `results/lighthouse/*.json` — the raw Lighthouse 13.5.0 reports. `results/summary.{json,md}` — the joined tables.

## Commands

```bash
# one frozen release binary for generation and measurement (never rebuilt during the run)
B=~/tmp/qa277/brain      # sha256 018520473d6e
node bench/autonomy/run.mjs --model claude-sonnet-5-5 --mode mcp --briefs briefs-21.json --tag final21b-sonnet --max-turns 200 --timeout 2400 --brain $B
node bench/autonomy/run.mjs --model claude-haiku-5-5  --mode mcp --briefs briefs-21.json --tag final21b-haiku  --max-turns 200 --timeout 2400 --brain $B
BRAIN=$B node bench/sites/final/measure.mjs --app bench/autonomy/results/final21b-sonnet/landing --site landing \
  --label sonnet --port 5310 --reps 20 --scratch ~/tmp/brainllm-final21b
#   … same for sonnet/panel (5330), haiku/landing (5350), haiku/panel (5360)
cp bench/autonomy/results/final21b-{sonnet,haiku}.json bench/sites/final/results/   # as generation-{sonnet,haiku}.json
node bench/sites/final/summarize.mjs --tag final21b
```

`measure.mjs` copies the app to the scratch dir (sources only) and runs, in order: `brain doctor --json` ·
`brain test --json` · `brain build` on the app as generated · `hyperfine -N` 10 runs cold (`rm -rf dist .brain` before
each) and warm · dist rules · `brain start` → Content-Type/Content-Encoding of every route and every `_b/*.js|css` ·
bytes per page = every same-origin file headless Chrome loads for the route (2.5 s), sized raw / shipped `.gz` /
brotli q11 computed here (dist has no `.br`, planned #231), each file counted once · Lighthouse 13.5.0 (pin of
`bench/a11y-seo/lighthouse.sh`) a11y+SEO on every page · `brain seo audit --json` · functional smoke (`smoke.mjs`,
semantic selectors) · HMR under `brain run`: 20 style edits + 20 script edits on one component, `bench/hmr/run.mjs`
clock (tool = dev-server compile log + client apply; total includes the OS file event), with UI state set before and
read after. Every process it starts is killed by PID; nothing stays listening.

**Patch for measurement only** (B1819/B1820 hrefs rewritten to `/` in the scratch copy): not needed in this run, all
four apps build as generated.

**Harness fixes in this run** (`smoke.mjs`, measurement only, no effect on the apps): (1) the pricing toggle is
re-queried after the click, because a prerendered island resumes on its first event and replaces its nodes, so the
old reference showed the pre-click `aria-pressed`; (2) validation messages are also read from the elements a field
names in `aria-describedby`/`aria-errormessage` (class names are minified in production, `.err` → `.e`); (3) the HMR
script edit tokenizes string literals from the start (the old regex could match the text *between* two literals and
produced `a: .'…'`, a B0002 on every edit); (4) the plan filter matches an option by value or label (`starter` vs
`Starter`).

Binaries: `brain` release sha256 `018520473d6e` for generation and measurement · `brain spec` sha256 `e745bbfd456e`
· repo HEAD `efc66c8` plus the working tree of 2026-10-13 · Node 26.8.1 · Chrome headless (system install) · macOS 26
(Darwin 25.6). The machine was shared with other sessions; the first run showed roughly ±30 % run-to-run noise on
build times.
