# BRAINLLM

> Web framework built for LLMs. One `.brain` file = one component (HTML + BrainScript + CSS). `brain` (Rust) compiles it to direct DOM, no virtual DOM. Read SPEC.md fully before writing code; nothing outside it exists.

## Docs
- [SPEC.md](SPEC.md): the whole contract, with a reference component. Also printed by `brain spec`.
- [examples/](examples/): valid apps and invalid cases with their expected error.

## Loop
`brain add` → edit → `brain check --json` → apply each `fix` literally until `[]` → `brain test`. MCP: `brain mcp`.
