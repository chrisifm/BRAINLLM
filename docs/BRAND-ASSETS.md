# Brand assets

Generated with the built-in image generator for BRAINLLM. Assets live in `docs/site/assets/` and are shared by the README, npm marketing README and landing. Generated artwork is illustrative; performance claims remain selectable, sourced text.

## Visual system

Obsidian backgrounds, acid lime highlights, chrome neural circuitry and restrained violet. The brain/circuit mark represents the agent/compiler feedback loop. Keep minimum contrast, clear focus styles and reduced-motion support. The landing has no font CDN, analytics or third-party UI dependencies.
