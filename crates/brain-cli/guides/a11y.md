# guide: a11y — accessibility (the build fails otherwise)

## When
Every component and view. Accessibility rules are security-grade defaults: they cannot be turned off, so write it
right the first time instead of fighting the checker.

## Steps
1. **Use the kit first** (no import needed): `<Button>` `<Input label>` `<Select label>` `<Checkbox>` `<Dialog>`
   `<Table>` `<Tabs>` `<Toast>` `<Menu>` `<Field>` `<ErrorState>` `<LangSwitch>`, layout `<Stack>` `<Row>` `<Grid>`
   `<Center>` `<Sidebar>` `<Container>`. They cover focus, labels, roles and every state (loading, disabled, error, empty).
2. **Structure:** one `<main>` and one `<h1>` per view (B0405); headings in order, never skip a level (B0404);
   landmarks with names (`<nav aria-label="Main">`, `<section aria-labelledby="t">`).
3. **Interaction:** clicks only on `<button>` or `<a href>` (B0402). A link navigates; a button acts.
   Buttons have visible text or an `aria-label` (B0406). No `tabindex` greater than 0 (B0407).
   Links have a name: text, `aria-label` or an image with alt (B0411); the text says where it goes, never only
   "click here" or "read more" (B0412).
4. **Forms:** every control has a label: kit `label="…"`, or `<label>Text <input …></label>`, or `for`/`id` (B0403).
   Errors near the field; a form-level error in `role="alert"`.
5. **Images and media:** `alt` on every image (B0401): describe what it shows, or `alt=""` when purely decorative;
   never a file name or a lone "image"/"logo" (B0413). `<iframe title="…">` (B0414). A `<video>` with sound or
   controls carries `<track kind="captions">` (B0415).
   Prefer `<Img src alt width height>` (sizes set, lazy, LCP priority chosen by the compiler).
6. **Color:** only token pairs that pass AA: fg/bg · muted/bg · accent/bg · ok/bg · bad/bg · on-accent on
   accent|ok|bad (B0408 insufficient contrast). `--line` is for borders only. No opacity or `color-mix()` on text.
7. **Motion:** animations inside `@media (prefers-reduced-motion: no-preference)` (B0409).
8. **Dynamic content:** status messages in `aria-live="polite"` or `role="status"`; `aria-*` references must point to
   elements that always exist (B0410), not to content inside `{#if}`.
9. **Lists:** `{#each}` with a key and an `{:empty}` branch that says what is missing and what to do.

## Verify
```bash
brain check --json          # B04xx errors with exact fixes where the fix is unique
brain test                  # every test also runs an accessibility audit of what it mounted
brain shot /route --text    # the accessibility outline (roles, names, headings) for mobile and desktop
brain doctor                # exit 0
```
Judgment calls (alt text, heading wording, which label) never get automatic edits: write them yourself.

## Common mistakes
| Mistake | Code | Fix |
|---|---|---|
| `<img src="/a.png">` | B0401 | `alt="What the image shows"` or `alt=""` if decorative |
| `<div on:click={open}>` | B0402 | `<button type="button" on:click={open}>` |
| `<input bind:value={q}>` alone | B0403 | `<Input label="Search" bind:value={q} />` |
| `<h1>` then `<h3>` | B0404 | use `<h2>` |
| two `<h1>` in a view | B0405 | one `<h1>`, the rest `<h2>`+ |
| icon-only button | B0406 | `aria-label="Close"` or visible text |
| `tabindex="3"` | B0407 | DOM order; `tabindex="0"` or `-1` only |
| `color: var(--muted)` on `--surface` with low contrast | B0408 | an AA pair from the token table |
| `@keyframes` used outside the media query | B0409 | wrap in `prefers-reduced-motion: no-preference` |
| raw `rgb(0 0 0 / .5)` backdrop | B0304 | `background: var(--scrim)` |

## Minimal correct example
```html
<meta props="open:bool~">
<section aria-labelledby="filters-title">
  <h2 id="filters-title">Filters</h2>
  <Checkbox label="Only available items" bind:checked={open} />
  <button type="button" aria-label="Clear filters" on:click={() => (open = false)}>×</button>
  <p role="status" aria-live="polite">{open ? 'Showing available items' : 'Showing all items'}</p>
</section>
<style>
  @media (prefers-reduced-motion: no-preference) { section { transition: opacity .2s; } }
</style>
```
